# Demonstration video checklist / script

Record your screen while running the program. Aim for a clear 3–5 minute video.

1. Show the project folder and `main.cpp`.
2. Show the compile command and successful compilation.
3. Run the application and introduce the main menu.
4. Add a student, then list and search for that student.
5. Update the student's details, then demonstrate delete only with a sample record.
6. Add one faculty member and one course.
7. Mark attendance and view attendance history.
8. Record a fee and view fee details.
9. Show the campus summary report.
10. Exit, run the app again, and show that file-based records remain saved.

Upload the recording to Google Drive or YouTube as an accessible link. Check link permissions before submitting. Do not show personal or confidential data in the recording.
